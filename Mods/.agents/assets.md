# Images and required files

Image dimensions, in pixels:

| Folder/file                 | Size      |
|------------------------------|-----------|
| `CardImages/*.png`          | 130x180   |
| `OrderIcons/*.png`          | 40x40     |
| `StructureImages/*.png`     | 260x260   |
| `UIImages/*.png`            | 260x260   |
| `Icon.png` (the mod's icon) | 50x50     |
| `Feature.png` (the mod's feature image) | 500x300 |

Every mod must also have a `LICENSE` file and a `ModDescription.txt`.
